STM32 双轮自平衡车
基于 STM32 的双轮自平衡车控制系统：MPU6050 姿态采集、互补滤波、串级 PID，实现直
立、行进与转向。

## 功能特性
- 姿态解算：MPU6050 ＋ 互补滤波，更新率 200Hz
- 双环控制：角度环（内环）＋ 速度环（外环），控制周期 5ms
- 通信调试：蓝牙串口在线调参、遥控指令解析、运行数据回传
- 人机交互：按键与指示灯状态提示
## 硬件清单
主控：STM32F103C8T6；传感器：MPU6050；电机：直流减速电机 ×2 带
编码器；驱动：TB6612；通信：HC-05 蓝牙模块；电源：7.4V 锂电池
## 系统架构（数据流）
MPU6050（I2C）→ 互补滤波（200Hz）→ 角度环 PD → 速度环 PI → PWM → 电机驱动
编码器（定时器捕获）→ 速度反馈 → 速度环（闭环）
## 控制算法
- 互补滤波：加速度计与陀螺仪数据融合，消除积分漂移，α 系数可调
- 串级 PID：角度环内环保直立，速度环外环控位移，转向环独立控制
